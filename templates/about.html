About Smart Parking Management System

Smart Parking Management System is a web-based application developed to automate parking slot management. Users can register, log in, reserve parking slots, make payments, and download invoices online.

The system also provides an administrator dashboard to manage users, parking slots, bookings, payment reports, and parking history.

This project is developed using Python Flask, MongoDB, HTML, CSS, and JavaScript to provide a secure, user-friendly, and efficient parking management solution.
